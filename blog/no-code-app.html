コードを1行も書かずに、iPhoneアプリを作った話

2026.10.19　管理者PAPA

ならピタの説明文にも書きましたが、私はこのゲームで、コードを1行も書いていません。プログラミング言語もわかりません。それでも iPhone アプリを作れたのは、AI の Claude（Anthropic）のおかげです。

役割分担

私の仕事は「こんなゲームにしたい」「ここをこう変えたい」と伝えること、そして実際に遊んで確かめることです。プログラムを書くのは Claude。できあがったプログラムをパソコンに取り込み、スマホで動かして、気になったところをまた伝える。その繰り返しで、少しずつ形にしていきました。

考えるのは人、書くのはAI、確かめるのはまた人。
この三拍子で、何十回も作り直しました。

Mac がなくても大丈夫だった

iPhone アプリといえば Mac が必要、というイメージがありました。でも今は、React Native と Expo という仕組みを使うと、アプリの組み立て（ビルド）や App Store への提出をインターネット上のサービスに任せられます。私の手元にあるのは Windows のパソコンだけですが、最後まで Mac を使わずに提出までたどり着けました。

大変だったこと

AI が書いてくれるとはいえ、何でも一発でうまくいくわけではありません。画面が崩れる、音が鳴らない、iPad で表示がずれる……。そのたびに画面を撮って、起きたことをできるだけ正確に伝えるのが、私のいちばん大事な仕事でした。

もうひとつは「決めること」です。難易度のバランス、機材の値段、日給の計算、表彰状の文面。AI は案をたくさん出してくれますが、どれにするかを決めるのは作る人の役目でした。

これから作ってみたい人へ

「作りたいもの」がはっきりしていれば、プログラミングができなくても、アプリづくりに挑戦できる時代になりました。うまくいかないときは、起きたことをそのまま伝えて、一緒に原因を探していけば大丈夫です。
